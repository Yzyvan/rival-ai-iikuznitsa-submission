# Канбан Vilar

Четыре колонки показывают задачи по сроку. Нажмите «Добавить», чтобы создать поручение, задачу по проекту, встречу или напоминание себе. Поиск и фильтры учитывают название, исполнителя и колонку. Чтобы переместить карточку, удерживайте её примерно треть секунды и перетащите. С клавиатуры откройте карточку и выберите «Переместить в колонку».

## Запуск примера

Из этого каталога выполните команды. Vite выведет локальный адрес приложения.

```sh
npm ci
npm run dev
```

Предпросмотр использует вымышленные задачи и хранит изменения в памяти вкладки. При перезагрузке восстанавливается исходный пример.

## Архитектура экрана

| Часть | Ответственность |
| --- | --- |
| `src/Tasks.tsx` | Список, отбор карточек, прокрутка колонок и жесты мыши и пальца. Карточка выбирается по ID. |
| `src/TaskForms.tsx` | Создание, просмотр и редактирование. Показывает доступные для конкретной карточки кнопки, ошибки и подтверждение действий. |
| `src/model.ts` | Данные, которые нужны экрану для показа задачи, исполнителя и срока. |
| `src/bindings.tsx` | Связь экрана с приложением, в которое его встроили. При смене фильтров экран передаёт новые значения, при выборе карточки — её ID, при действии — введённые поля. |
| `src/preview.tsx` | Самостоятельный пример подключения этих же компонентов на тестовых данных. |

Для встраивания импортируйте `Tasks` и `TaskBindingsProvider` из `src/index.ts`. Передайте реализацию `TrackerBindings` свойством `bindings`. Если пользователь открывает карточку из другой вкладки, используйте `TaskDetail` внутри того же провайдера. Для самостоятельной страницы подключите `src/style.css`.

```tsx
<TaskBindingsProvider bindings={bindings}>
  <Tasks />
</TaskBindingsProvider>
```

## Проверка в Chromium

```sh
npm run build
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node checks/preview.cjs
```

Проверка поднимает локальную раздачу собранной страницы, заполняет все четыре формы, перемещает и редактирует карточки, проверяет отмену, фильтр и перезагрузку. Она также проверяет, какие файлы запрашивает браузер.
